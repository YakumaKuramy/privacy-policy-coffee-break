## 🔒 Compromisso com a Privacidade

Nossos jogos são desenvolvidos com foco na experiência do usuário e no respeito à sua privacidade:
- **Não coletamos dados pessoais sensíveis** sem consentimento.
- Os dados de progresso (*save games*) são armazenados localmente no dispositivo do usuário.
- Não utilizamos telemetria invasiva ou práticas abusivas de dados.
